# ios-pipeline-lab

An iOS delivery pipeline built from scratch, one step at a time: Fastlane, code signing with match, a pull-request gate on GitHub Actions, tag-driven TestFlight uploads, release notes that write themselves.

Each part of the series is a tag, so the code you read matches the article you are reading.

| Tag | Part |
|-----|------|
| — | Part 1: Fastlane from zero |

## Requirements

- Xcode 26
- Ruby 3.3 (see `.ruby-version`)
- `bundle install` at the repository root
